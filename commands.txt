Build and Run Instructions for ImCloneDetect
=============================================

1. Build the project (from the root directory):
   mkdir build
   cd build
   cmake ..
   cmake --build .

2. Run the main application:
   From the build directory:
   ./main/main  (on Linux/Mac)
   main\main.exe  (on Windows)
   
   Or from the root directory:
   ./build/main/main  (on Linux/Mac)
   ./build/main/main.exe  (on Windows)

3. Run with test inputs:
   ./build/main/main < commands.txt

4. Run tests:
   ./build/main/test  (on Linux/Mac)
   main\test.exe  (on Windows)
